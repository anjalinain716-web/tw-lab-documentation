# GitHub

## 1. Introduction

GitHub is a web-based platform used to host Git repositories and support collaboration among developers. It allows users to store, manage, share, and work on projects online.

## 2. Git vs GitHub

Git is a distributed version control system used to track changes in files. GitHub is an online platform that hosts Git repositories and provides collaboration features.

## 3. GitHub Repositories

A repository is a storage location for project files, documentation, and version history. Repositories can be public or private.

## 4. Creating a Repository

A GitHub repository can be created by signing in to GitHub, selecting New Repository, entering a repository name, choosing its visibility, and clicking Create Repository.

## 5. README File

A README file provides information about a project, such as its purpose, features, installation instructions, usage, and contribution guidelines. It is commonly written in Markdown.
